## 🧠 策略引擎设计

### 多因子评分体系

策略综合以下四大维度，总分100分，**60分以上**才会触发买入：

1. **技术面 (60%)**
   - 均线多头排列 (MA5>MA10>MA20)
   - 量能配合（量比>1.5且收盘上涨）
   - 突破形态（创近5日新高）
   - MACD金叉/红柱放大
   - 涨幅控制（2%~8%为优）

2. **资金面 (30%)**
   - 主力净流入估算
   - 换手率活跃度
   - 量比放大

3. **板块情绪 (5%)**
   - 当日热点板块加分

4. **市场情绪过滤**
   - 涨跌家数比 < 25% → 观望
   - 涨跌家数比 > 85% → 观望
   - 跌停家数 > 30 → 观望

## 🎯 自进化系统

### 核心理念

> **"赚要知道为什么赚，亏要知道为什么亏"**

### 自进化规则

系统在**每日收盘后**自动运行分析，根据历史交易结果调整策略参数：

| 触发条件 | 调整动作 | 目的 |
|-----------|---------|------|
| 胜率 < 40% | 降低买入阈值 | 减少无效交易 |
| 胜率 > 60% | 提高买入阈值 | 提高进场标准 |
| 连续小赚 | 放宽止盈目标 | 让利润奔跑 |
| 连续大赟 | 收紧止损 | 减少回撤损失 |
| 牛市赚钱 | 加大板块加分 | 跟随热点 |
| 持仓过久亏损 | 缩短最大持股天数 | 提高资金周转率 |

### 进化历史记录

所有参数变更都会记录在 `data/evolution/evolution_history.json`，可追溯策略迭代过程。

## ⚠️ 重要声明

1. **本系统为模拟交易，不会真实下单**。所有交易均为虚拟，仅供策略研究和回测。

2. **数据源来自腾讯财经公开接口**，在国外服务器访问，偶发网络波动可能导致数据延迟。

3. **策略不构成投资建议**。A股市场风险极高，短线交易可能导致重大损失。

4. **自进化需要时间**。策略优化基于历史交易数据，前期（10-20笔交易内）主要是数据积累阶段。

5. **与老翁的配合**。系统自动执行的同时，建议老翁定期查看报告，根据自己的行业观察和盘感进行人工干预。
